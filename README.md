# Automated-Gardening-System (AGS)
Automated Gardening System integrating embedded controls, environmental sensing, automated irrigation, and AI-assisted supervision using Arduino and Raspberry Pi.

A senior project developed at Cal Poly SLO to create a fully automated, controlled environment for plant growth.

AGS uses an **Arduino Mega and Raspberry Pi** to monitor and control environmental conditions including temperature, humidity, soil moisture, lighting, ventilation, and irrigation.

## Features

- Automated environmental monitoring and control
- Temperature, humidity, and soil moisture sensing
- Automated irrigation, lighting, heating, humidification, and ventilation
- Arduino + Raspberry Pi control architecture
- Live web dashboard and data logging
- AI-assisted environmental supervision
- Manual and automated operating modes
